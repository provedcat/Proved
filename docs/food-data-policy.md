# PROVED 사료 데이터 기준

사용자와 합의한 적용 기준: 2026-11-18. 새 기준을 제품별로 임의 적용하지 않는다.

| 항목 | 적용 기준 |
|---|---|
| 성분 출처 | 국내 라벨 우선 / 해외 공식 성분 적용 / 국내·해외 항목별 보완. 채택한 출처를 기록한다. |
| 표시 열량 | 국내 공식 값 / 해외 공식 값. 출처가 기록되지 않은 값은 임의 분류하지 않는다. |
| 열량 미공개 | 보증성분으로 추정하고 습식 주식에는 기존 보정 후 적용한다. 계산할 수 없을 때만 비운다. |
| Ca:P | 등록한 성분 출처의 칼슘 ÷ 인. 최소 보증값이라는 이유로 비우지 않는다. |
| NFE | max(0, 100 - 단백질 - 지방 - 회분 - 섬유 - 수분). 필수 성분 누락은 0으로 대신하지 않는다. |
| DM | 등록한 성분과 수분으로 환산. 수분 미공개면 계산하지 않는다. |
| 주식·보조식 | 제조사 완전식 문구 또는 검수자 확인으로 분류한다. |
| 판본 | 국내 구판이 실제 유통 중이면 국내 유통 판본 우선. 국내 공식 신판 / 해외 공식 신판 / 불일치 보류는 검수자가 확인한다. |
| 검수 상태 | 관리자 등록은 등록 경로, 검수 전·완료는 성분 검수 상태. 성분 검수가 끝나면 열량이 비어도 완료다. |

추정 열량(kcal/kg): `(단백질×3.5 + 지방×8.5 + NFE×3.5)×10`.

| 수분 | 지방 ≤2% | 지방 >2% |
|---|---:|---:|
| ≥85% | 1.82 | 1.26 |
| ≥82%, <85% | 1.41 | 1.22 |
| <82% | 1.33 | 1.28 |

이 계수는 기존 Apps Script의 습식 주식 보정계수다. 공식 표시 열량이나 건식·습식 보조식에는 적용하지 않는다. 계산치는 실측치가 아니다.

## 구현 위치

- 정보 상태 공통 렌더러·계산 검증: `js/food-data-policy.js`
- 저장 시 계산: `public.proved_food_numeric_policy`와 `aa_apply_food_numeric_policy` 트리거(고양이·강아지 공통)
- 기존 데이터 환산 정렬: `scripts/align-food-data-policy.sql`. 변경 전 계산값은 source_urls의 `policy_alignment_20261118` 기록에 보존한다.
- 제품별 출처 구분: source_urls의 `purpose: information_basis` 레코드. 성분과 열량의 시장을 서로 추정해서 덮어쓰지 않는다.
- 제품별 자유 메모는 이력으로 보존하지만 공통 정책 설명을 대신하지 않는다.
