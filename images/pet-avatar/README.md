# MY PET 이미지 교체

렌더용 원본은 `assets/`의 투명 PNG(1024×1024)입니다. 같은 레이어를 고칠 때는 파일명과 캔버스 크기를 유지하고 파일을 교체하세요. 형태의 `_shape`는 투명도 마스크이며 `_shadow-colorburn`, `_light-softlight`는 같은 형태의 명암입니다. 색상과 세 종류의 패턴은 현재 형태 마스크에 맞춰 잘립니다.

눈색, 눈패턴, 볼터치, 코 PNG를 교체했다면 저장소 루트에서 `python scripts/generate-pet-avatar-thumbs.py`를 실행해 `thumbs/`의 확대 선택 이미지를 다시 만드세요. 얼굴형, 색상, 패턴은 원본 PNG를 선택 화면에도 사용합니다.

새 선택지를 추가하거나 이름을 바꿀 때는 `js/pet-avatar-renderer.js`의 목록과 파일 경로를 함께 바꾸세요. 이미 펫에 저장된 설정 키를 변경한다면 기존 값의 복원도 확인해야 합니다. 에셋을 변경해도 저장된 256×256 WebP는 자동으로 바뀌지 않습니다. 사용자가 아바타 편집 화면에서 다시 저장하면 새 이미지가 생성됩니다.
